# 把经验整理成按需加载的技能

主题：工具设计、MCP 与 Skills

编辑版：1.1 · 2026-10-16

来源：https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills

## 先抓住这个问题

团队每次整理资料都要重新向助手解释同一套步骤，格式规范和脚本又散落在不同位置。怎样把这些经验组织成能被发现和复用的操作知识，同时避免每次任务都加载整套手册？

## 理解方法

简短描述负责触发，主体说明负责执行，附属资源承载细节。分层披露减少一次性塞入全部材料。

## 适用边界

技能内容需要可信、可维护。技能说明不能替代真实工具权限，也不能保证脚本运行结果正确。

## 换个场景想想

【原创演练】整理“每月资料整理”技能：写清何时使用、输入输出、执行顺序和验收方法。把少用的格式规范放附录，而不是全部挤进入口说明。

## 把它带回自己的工作

选一个你正在做的小任务，写下能借鉴的一点、暂不适用的一点，以及验证效果需要观察的证据。案例与练习均为本学习库原创，用于迁移理解，不代表来源文章的实验结果。

## 可选回想

1. 暂时合上导读：用自己的话说明这篇文章要解决什么问题，以及它的主要方法。

2. 哪些内容放技能入口，哪些内容放附属文件？

3. 这篇方法有什么适用边界？你会怎样检查它在自己的任务中是否有效？

## 对照要点

1. 文章介绍用指令、脚本和资源组织技能，并按需加载，让通用 Agent 获取特定领域的操作知识。简短描述负责触发，主体说明负责执行，附属资源承载细节。分层披露减少一次性塞入全部材料。

2. 入口保留触发条件和核心流程，细节按需读取。说明资源路径、维护责任和结果验证。

3. 技能内容需要可信、可维护。技能说明不能替代真实工具权限，也不能保证脚本运行结果正确。
