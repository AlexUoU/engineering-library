一个轻量的学习流程

先想一想：这篇文章能帮助我解决什么问题？读导读时留意方法和适用边界。愿意的话，合上内容，用自己的话写一点理解，再展开对照要点。几天后回来看看“上次的思考”，也可以用新场景重新解释一次。所有步骤都可跳过。

不知道从哪篇开始？

初次接触 Agent，从“先选最简单的方案”开始；正在做知识助手，先看上下文与检索；任务经常中断，先看长任务交接；对结果不放心，先看评测。遇到具体问题时，也可以直接搜索本地导读。

术语随手查

Agent / 智能体

由模型根据任务进展选择行动、调用工具并继续处理的系统。仍然需要目标、权限与停止条件。

Workflow / 工作流

主要执行路径由程序预先安排的流程。明确、重复的任务通常可以先考虑这种方式。

Context / 上下文

一次模型调用能看到的信息，包括指令、消息、工具和资料。有限窗口需要筛选，而非无限累加。

RAG / 检索增强生成

先从资料库寻找相关内容，再把找到的证据交给模型生成回答。找到什么与怎么回答，需要分别检查。

Embedding / 向量表示

将文本转换成可用于相似性比较的数值表示。相似不代表事实相同或来源可靠。

BM25 / 关键词检索排序

根据词项匹配等因素排列结果的方法，适合精确名称、编号等查询；可与语义检索配合。

MCP / 模型上下文协议

连接模型应用与外部工具、资料的一种协议。统一连接方式不等于自动授予权限。

Skill / 技能

按需读取的一组操作知识、指令与资源，帮助 Agent 完成某类任务。

Harness / 执行框架

把模型调用、工具执行、状态传递与循环控制连接起来的系统安排。

Eval / 评测

用明确任务和检查方法观察系统表现。本文库里的可选回想用于个人学习，不是能力认证。

Trace / 执行轨迹

系统行动与工具结果的记录。轨迹可以帮助排查，但最终还要确认环境中的实际结果。

Sandbox / 沙箱

限制程序可触及资源的执行环境。实际限制取决于具体实现和配置。

版本与来源校验值

版本保存某个时点的本地内容；校验值用于比较正文是否变化。校验值本身不包含原文，也不能用来还原原文。

资料范围与备份

这是一套短篇中文导读与原创练习，不是全文译本。来源全文需联网阅读。新增与修订会建立来源版本，但不会自动编写新导读或题目。完整迁移请停止服务后复制整个文件夹；个人学习记录也可从“我的思考”导出。分发 ZIP 不包含私人回答。
