# 独立 HTML 分支

2.0.0 是首个独立 HTML 阅读器版本，与原服务器/App 分支并存。

发布目录 output/standalone/<版本号>/。每个版本包含独立 HTML、release.json（SHA256、内容数量、记录格式）和验收结果。已生成版本不覆盖；构建器遇到同名目录拒绝写入。后续功能版本增加次版本号，修复增加补丁号，不删除历史产物。文章 v1/v2 等是内容版本，与阅读器版本号独立。

制作：python3 standalone/build.py <新版本号>，输入为已有完整 ZIP；不会下载、翻译或重建旧包。

使用：完整下载 HTML 后，在 Chrome 打开。所有正文与图片内置；官方原文和外部引用仍需网络。旧文章版本没有对应正文时，沿用原版缺失说明，不伪造内容。

学习记录 schema 1 与原版导出格式兼容。旧版“我的思考”导出 JSON，在新 HTML 的“我的思考”导入。升级前导出，升级后导入。导入合并且重复导入不重复添加；导入前自动发起一份备份下载。请确认浏览器实际保存了文件。

浏览器本地存储不是可靠的唯一备份。移动 HTML、更换浏览器、清理数据可能丢失自动保存记录。导出的 JSON 含个人回答，请自行保管。HTML 中不包含制作机器的学习记录。

已验证：26 篇双语正文、86 个内容版本、图片引用内置、无 fetch 调用、阅读状态、草稿、思考、模拟重新载入持久化、导出/导入/去重/非法导入原子拒绝。
未验证：自动化工具禁止 file://，因此未完成 Chrome 本地文件实机打开、实际下载文件与上传导入交互、移动端视觉验收。acceptance.json 不代表这些流程通过。
